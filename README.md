# 🇷🇺: Официальный репозиторий медиа-материалов интернет-телеканала strm.
В cocoa.labs мы стараемся делать так, чтобы наши проекты были максимально доступны и открыты. Данный репозиторий представляет из себя сборник материалов, нужных для регионального вещания.
---
## Можно ли сделать поток независимым от региона?
В случае если регион указывать необязательно или Вы не хотите этого делать, можно заменить название региона на условное названия вещателя.
## Есть ли лицензия у этого репозитория?
На данный репозиторий наложена лицензия **The Unlicense**, которая даёт полностью свободно распространять материалы. Тем не менее, это не освобождает от нужны изменять и адаптировать каким-либо образом файлы, данные для вещания и публикаций.
