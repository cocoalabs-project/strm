# <img width="32" height="32" alt="Логотип интернет-канала" src="https://github.com/user-attachments/assets/6cf519f9-056e-49bb-ae5e-26fd9af604a9" /> 🇷🇺: Официальный репозиторий медиа-материалов интернет-телеканала strm.
В cocoa.labs мы стараемся делать так, чтобы наши проекты были максимально доступны и открыты. Данный репозиторий представляет из себя сборник материалов, нужных для регионального вещания.

ССЫЛКА НА Figma: https://www.figma.com/community/file/1699432171759801106

## Можно ли сделать поток независимым от региона?
В случае если регион указывать необязательно или Вы не хотите этого делать, можно заменить название региона на условное названия вещателя.

## Есть ли лицензия у этого репозитория?
Данный репозиторий лицензирован под **CC0 1.0** - эта лицензия выпускает материал(ы) в общественное достояние, а автор отказывается от авторских прав настолько, насколько позволяют законы. Тем не менее, это не освобождает от нужды изменять и адаптировать каким-либо образом файлы, данные для вещания и публикаций.
